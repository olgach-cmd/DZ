# Домашнее задание

## Описание
Набор Python-модулей для работы с банковскими операциями

## Требования
- Python 3.14+
- Poetry (менеджер зависимостей)

## Зависимости
+ ### Основные
  Python 3.14+
+ ### Инструменты разработки
  * **flake8** >=7.3.0 (Проверка кода на соответствие стилю написания, который использует PEP 8 в качестве руководства.)
  * **black** >=26.5.1 (Автоматическое форматирование кода.)
  * **isort** >=8.0.1 (Сортировка импортов в коде.)
  * **mypy** >=2.3.0 (Проверка типов переменных в коде.)
  * **pytest** >=9.1.1 (Фреймворк для написания и запуска тестов.)
  * **pytest-cov** >=7.1.0 (Плагин для проверки покрытия кода тестами.)

## Установка:
1. Клонируйте репозиторий:
```
git clone https://github.com/olgach-cmd/DZ.git
cd DZ
```
2. Установите зависимости:
```
poetry install
```
## Тестирование:

В проекте реализованы тесты для проверки корректности работы функций из модулей *masks*, *widget* и *processing*. Для их запуска используется фреймворк *pytest*.

**Запуск всех тестов:**
```
poetry run pytest
```
**Запуск тестов с выводом процента покрытия кода в терминал:**
```
poetry run pytest --cov=src
```
**Генерация подробного HTML-отчета о покрытии:**
```
poetry run pytest --cov=src --cov-report=html
```
После выполнения этой команды в корне проекта обновится папка *htmlcov*. 
Чтобы просмотреть детальный отчет о том, какие строки кода покрыты тестами (подсвечены зеленым), 
а какие нет (подсвечены красным), откройте файл *htmlcov/index.html* в любом браузере.

## Список модулей и функций в папке src:

+ ### masks
  - **get_mask_card_number** - Функция маскировки номера банковской карты если номер = 16 символов возвращает маску если нет - возвращает ошибку
  - **get_mask_account** - Функция маскировки номера банковского счета если номер ≥4 символов возвращает маску если нет - возвращает ошибку
+ ### widget
  - **mask_account_card** - Принимает на вход строку тип и номер карты или счета в формате Visa Platinum 7000792289606361, или Maestro 7000792289606361, или Счет 73654108430135874305.
    Возвращает строку с замаскированным номером в формате Visa Platinum 7000 79** **** 6361 или Счет **4305
  - **get_date** - Принимает на вход строку с датой в формате "2024-03-11T02:26:18.671407" и возвращает строку с датой в формате "ДД.ММ.ГГГГ" ("11.03.2024").
+ ### processing
  - **filter_by_state** - Принимает список словарей и опционально значение для ключа *state* (по умолчанию 'EXECUTED'). Функция возвращает новый список словарей, содержащий только те словари, у которых ключ
    *state* соответствует указанному значению.
  - **sort_by_date** - Принимает список словарей и необязательный параметр *reverse*, задающий порядок сортировки. При *reverse = True* сортирует по убыванию (задан по умолчанию),
    при *reverse = False* - сортировка по возрастанию. Функция возвращает новый список, отсортированный по дате (date).
+ ### generators
  - **filter_by_currency** - Генераторная функция, принимает на вход список словарей, представляющих транзакции,
    и возвращает итератор, который поочередно выдает транзакции, где валюта операции соответствует заданной
    (например, USD).
  - **transaction_descriptions** - Генераторная функция, принимает на вход список словарей, представляющих транзакции,
    и возвращает описание каждой операции по очереди (например, "Перевод организации")
  - **card_number_generator** - Генераторная функция, выдает номера банковских карт в формате XXXX XXXX XXXX XXXX, где X — цифра номера карты.
    Генератор может сгенерировать номера карт в заданном диапазоне от 0000 0000 0000 0001 до 9999 9999 9999 9999.
+ ### decorators
  - **log** - Декоратор с необязательным параметром *filename*, автоматически логирует начало и конец выполнения функции, а также ее результаты или возникшие ошибки.
    Если *filename* задан, логи записываются в указанный файл. Если не задан - логи выводятся в консоль.
+ ### utils
  - **list_transactions_from_file** - Функция принимает на вход путь до JSON-файла и возвращает список словарей с данными о финансовых транзакциях.
    Если файл пустой, содержит не список или не найден, функция возвращает пустой список.

+ ## Список тестов:

+ ### test_masks
  - **get_mask_card_number** - Тестирование правильности маскирования номера карты.
  Проверка когда на вход подается строка состоящая не из цифр. Проверка неверного количества цифр.
  - **get_mask_account** - Тестирование правильности маскирования номера.
  Проверка когда на вход подается строка состоящая не из цифр. Проверка неверного количества цифр.
+ ### test_widget
  - **mask_account_card** - Проверка правильности маскировки карт и счетов. Проверка поведения, когда на вход подается неккорректное число цифр номеров карт, счетов, строка  без наименования или только номер.
  - **get_date** - Проверка правильности преобразования дат. Проверка поведения при несуществующей дате.
+ ### test_processing
  - **filter_by_state** - Проверка фильтрации списка словарей по заданному статусу state. Проверка работы функции при отсутствии словарей с указанным статусом state в списке. проверка работы, если state не задан.
  - **sort_by_date** - Проверка работы сортировки списка словарей по датам в порядке убывания и возрастания при заданном и отсутствующем reverse. Проверка фильтрации при одиноковых датах но с разным временем.
+ ### test_generators
  - **filter_by_currency** - Проверка корректности фильтрации по заданной валюте. Проверка поведения при обработке пустого списка или списка без соответствующих валютных операций.
  - **transaction_descriptions** - Проверка корректности выдаваемых данных. Проверка поведения при обработке пустого списка.
  - **card_number_generator** - Тестирование правильности выдаваемых номеров карт, включая форматирование. Проверка поведения при крайних значений диапазона.
+ ### test_decorators
  - **log** - Проверка вывода лога в файл и в консоль при корректной работе и ошибке.
+ ### test_utils
  - **list_transactions_from_file** - Проверка правильности вывода списка транзакций. Проверка поведения если файл пустой, содержит не список или не найден.
