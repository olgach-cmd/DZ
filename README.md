# Домашнее задание

## Установка:
1. Клонируйте репозиторий:
```
git clone https://github.com/olgach-cmd/DZ.git
```
2. Установите зависимости:
```
poetry install
```

## Список модулей и функций в папке src:

+ ### masks
  - **get_mask_card_number** - Функция маскировки номера банковской карты если номер = 16 символов возвращает маску если нет - возвращает ошибку
  - **get_mask_account** - Функция маскировки номера банковского счета если номер ≥4 символов возвращает маску если нет - возвращает ошибку
+ ### widget
  - **mask_account_card** - Принимает на вход строку тип и номер карты или счета в формате Visa Platinum 7000792289606361, или Maestro 7000792289606361, или Счет 73654108430135874305.
    Возвращает строку с замаскированным номером в формате Visa Platinum 7000 79** **** 6361 или Счет **4305
  - **get_date** - Принимает на вход строку с датой в формате "2024-03-11T02:26:18.671407" и возвращает строку с датой в формате "ДД.ММ.ГГГГ" ("11.03.2024").
+ ### processing
  - **filter_by_state** - Принимает список словарей и опционально значение для ключа *state* (по умолчанию 'EXECUTED'). Функция возвращает новый список словарей, содержащий только те словари, у которых ключ
    *state* соответствует указанному значению.
  - **sort_by_date** - Принимает список словарей и необязательный параметр *reverse*, задающий порядок сортировки. При *reverse = True* сортирует по убыванию (задан по умолчанию),
    при *reverse = False* - сортировка по возрастанию. Функция возвращает новый список, отсортированный по дате (date).
